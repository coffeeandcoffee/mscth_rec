OBJECTIVE
---------
Classify EEG data between first and last A-press into
'about_to_skip' and 'not_about_to_skip' class blocks,
then count available ML samples per class per participant.

PARAMETERS
----------
  Pre-skip window:  3.0s (before each A press)
  Sample length:    3.0s
  Overlap:          80%
  Stride:           0.6s

CLASSIFICATION LOGIC
--------------------
  For each consecutive A-press pair (t_i, t_{i+1}):
    gap <= 3.0s → entire interval = about_to_skip
    gap >  3.0s → [t_i, t_{i+1}-3.0] = not_about_to_skip
                       [t_{i+1}-3.0, t_{i+1}] = about_to_skip
  Adjacent same-label blocks are merged.

SAMPLE COUNT FORMULA
--------------------
  n = floor((block_duration - 3.0) / 0.5999999999999999) + 1
      if block_duration >= 3.0s, else n = 0
