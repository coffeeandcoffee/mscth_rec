# Analysis & Documentation

Incremental, documented data quality checks and analyses for the EEG TikTok study (P4–P31).

## Procedure

Each analysis step is stored in its own timestamped folder:

```
analysis_and_documentation/
├── README.md                          ← this file
├── YYYYMMDD_HHMMSS_<description>/
│   ├── analysis.py                    ← self-contained analysis script
│   ├── description.txt                ← what was done, why, and key findings
│   └── images/                        ← generated figures and tables
├── YYYYMMDD_HHMMSS_<next_step>/
│   ├── ...
```

### Folder naming

`<datetime>_<short_description>` — e.g. `20260309_155600_basic_quality_check`

### Contents of each folder

| File | Purpose |
|------|---------|
| `analysis.py` | Standalone script that reads from `../data/` and writes outputs to `images/` |
| `description.txt` | Plain-text summary: objective, method, findings, any exclusion decisions |
| `images/` | Publication-ready figures and tables generated by the script |

### Running an analysis

```bash
cd analysis_and_documentation/<folder>
python analysis.py
```

All scripts are designed to be run from within their own folder and reference data via relative paths (`../../data/`).
